Tentang Saya

Saya Hikma Nazwa Agustin, mahasiswa Sistem Informasi yang berfokus pada pengembangan aplikasi web dan solusi perangkat lunak yang fungsional, rapi, serta intuitif untuk digunakan. Berbekal pemahaman di bidang Sistem Informasi, saya memiliki ketertarikan mendalam terhadap cara kerja perangkat lunak dari balik layar mulai dari perancangan struktur dasar hingga bagaimana sebuah sistem dapat menyelesaikan tantangan nyata secara efektif dan efisien.

Saya selalu antusias dalam menghadapi tantangan teknis, memahami alur kerja software development, dan mengembangkan keterampilan coding secara berkelanjutan. Tujuan utama saya adalah menguasai alur pembuatan aplikasi secara menyeluruh, mulai dari perancangan antarmuka pengguna yang responsif, penyusunan logika pemrograman, hingga pengelolaan data. Pendekatan belajar saya berpusat pada praktik langsung membangun proyek secara mandiri, mengeksplorasi teknologi baru, melakukan iterasi kode, dan terus menyempurnakannya secara konsisten.

Fokus saya saat ini: HTML, CSS, Bootstrap, dan JavaScript dasar, serta kebiasaan menyimpan pekerjaan di Git dan GitHub.
